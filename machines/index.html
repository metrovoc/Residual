Machines

Each machine performs one operation of a model, with the same arithmetic as PyTorch. A machine takes its main input on its back and, if it has one, its side input on any other face, and sends its result out of its front: see Machines and Cables. Right-click a machine to change its settings and see what it computes.

Every machine comes out of the Fabricator. The simple ones need no design; the rest need a photomask of the spec that describes them, verified on a Bench or salvaged from the ruins.

No design needed

  • Embedding Table: token ids to vectors.
  • Position Table: a learned vector for every position.
  • Residual Junction: addition, and with it the residual stream.
  • Gate: one signal opening or closing another.
  • Scaler: multiplied by a constant, usually 1/√d.
  • Causal Mask: the future hidden.
  • Head Splitter and Head Merger: multi-head attention from parts.
  • Delay Line: a fixed look back in time.
  • Concatenator: two vectors joined end to end.

From a design

  • Matrix Multiplier, from Matrix Multiply: grids multiplied, keys compared with queries.
  • Softmax, from Softmax: scores turned into weights.
  • Linear Layer, from Linear Layer: a learned matrix, the workhorse of every model.
  • Activation, from GELU: a nonlinear function on every number.
  • Normalizer, from Layer Norm: vectors kept at a steady size.
  • Attention Head, from Attention: multi-head attention in one machine.
  • Feed-Forward Block, from Feed-Forward Block: widen, bend, project back.
  • Transformer Block, from Transformer Block: a whole transformer layer.
