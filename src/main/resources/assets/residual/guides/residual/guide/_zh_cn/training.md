# 训练

训练就是把同一步重复成千上万次：让模型处理一批文本，衡量它错得有多离谱，算出每个权重该往哪个方向移动才能少错一些，再把它们挪动一点。

## 损失

语言模型会给每一个可能的下一个词元打分。Softmax 把这些分数变成概率：

![softmax](/formulas/softmax.png)

损失是**交叉熵**：在每个位置上，模型对实际出现的下一个词元有多意外，再对所有位置取平均。

![cross-entropy](/formulas/cross_entropy.png)

一无所知的模型会把赌注平均押在全部 V 个词元上，所以起点接近

![chance](/formulas/chance.png)

每条曲线都从这里开始。损失为 0 意味着对每个下一个词元都有十足把握，诚实的模型在真实文本上做不到这一点。损失按字符计算：一个词元的损失由它代表的字符平摊，所以借助[分词器](tokenizers.md)阅读的模型，可以与逐字符阅读的模型公平比较。对于只有部分位置有正确答案的数据集，核心还会衡量**准确率**：得分最高的词元有多常是正确的那个。

## 练习与测试

**训练损失**在模型练习用的批次上测得，取最近若干步的平均。**测试损失**在练习中从未出现的样例上测得。两者分道扬镳时，即训练损失仍在下降，测试损失却停滞或上升，说明模型在死记练习内容，而没有学到能推广的东西。评判模型只看测试。

## 设置

**学习率（LR）**。每一步让权重移动多远。太小，很长时间都不见动静；太大，损失会上蹿下跳甚至爆炸。核心用 AdamW 训练，这是大多数语言模型所用的优化器。它按每个权重最近梯度的大小来缩放其步长，所以学习率相当直接地决定了步长：

![AdamW](/formulas/adamw.png)

其中取常用的 β₁ = 0.9、β₂ = 0.999，权重矩阵的权重衰减 λ = 0.01。前 20 步从零预热到完整的学习率。

**批量**。每一步看多少条序列。批次越大，梯度越稳，但每步的开销也越大。

**裁剪**。梯度裁剪在迈步之前限制整个梯度的大小：

![clipping](/formulas/clip.png)

它能挽救偶尔出现的巨大梯度，而不改变平常的步。学习率若在每一步都太大，它也无能为力。

**速度**。「观察」训练得足够慢，便于跟着曲线看；「最快」则让核心全速训练。

## 解读曲线

- **开头平坦，随后骤降**：模型找到了一种机制。注意力模型常常如此。
- **先降后平，停在目标之上**：模型已学会它能看到的一切。给它更多可用的东西：更长的上下文、更宽、更多层。
- **锯齿状并且攀升**：步子太大了。调低学习率。
- **两种损失都低得可疑**：有什么让模型看到了答案。核心会标记出偷看后文的模型。

## 看它学习

模型训练时，每两秒就有波穿过它的方块。一道青色脉冲从词元走到损失，批次到达哪台机器就点亮哪台，亮度取决于它输出的值。随后一道琥珀色脉冲从损失往回走，按到达每台机器的梯度大小将其点亮。回程中始终暗着的机器几乎学不到东西：几乎没有梯度到达它。

每台机器上方悬浮着它对一个练习样例的输出：向量每个元素一根柱，矩阵每个元素一格，大于零为琥珀色，小于零为蓝色。注意力头则显示它的模式，即每个词元关注哪些先前的词元。看向全息图，可读出准星下的值。没有在训练时，手持<ItemLink id="tensor_probe" />也能看到全息图。

## 训练何时停止

按下「停止」，或模型中的某台机器发生改变时，训练就会停止。损失发散时也会停止：变成 NaN，或攀升到远高于起点。打捞模型还有一份**预算**：每轮可走的步数有限，用完后需重置权重再试。

「重置」会丢掉学到的权重，让下一轮从头开始。「校验」会重新读取模型并报告问题，但不训练。
