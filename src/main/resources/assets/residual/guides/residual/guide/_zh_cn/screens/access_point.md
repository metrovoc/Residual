# 接入点的界面

对接入点使用即可打开。终端能覆盖多远，见[存储](../storage.md)。

一个放中继卡的槽，和一个表示覆盖范围的标记。

<residual:Shot name="access_point_card" alt="没有中继卡的接入点">
  <residual:Part name="card">
    **中继卡**：调谐到模型服务器的中继卡。放在这里，无线终端在那台服务器的中继器覆盖的任何地方都能连到这个网络。
  </residual:Part>
  <residual:Part name="light">
    **它的覆盖**：网络上的链路增幅器有电时为青色，中继卡接通时为琥珀色。指向它可看到覆盖多少格。
  </residual:Part>
</residual:Shot>
