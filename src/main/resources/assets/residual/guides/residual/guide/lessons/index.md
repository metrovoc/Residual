# Lessons

Each lesson adds one idea to your model and retraces the paper where that idea first worked. The goal is set where
the idea is needed: a model without it stalls above the line, a model with it gets there.

Every page explains the idea and its math, then shows one way to build it at the end. Try your own way first. The
reference build is a starting point, not the only answer.

<SubPages />

Between the lessons sit [cases](../cases/index.md): broken models to diagnose.
