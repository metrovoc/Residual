# 飞行

<ItemLink id="flight_frame" />穿在胸甲栏。只要它有电，并装着一位能带在身上、通过驾驶测试的驾驶模型，穿戴者就能像创造模式那样自由飞行：连跳两下起飞，停在哪里就悬停在哪里。飞行时每刻耗 80 FE，充满 400,000 FE 的背架大约能飞四分钟。制造机用 Transformer 光掩模做出它。

## 驾驶

驾驶模型像往收纳袋里放东西一样装进去：在物品栏里拿起一个检查点，用它右键点击背架。空手右键点击背架，就能把驾驶取出来，回到检查点上。背架的提示会写明它的驾驶；驾驶稳不住背架时也会说明：驾驶必须通过驾驶测试，而且小到能带在身上。

## 电力

拿着背架对<ItemLink id="energy_cell" />使用，就能从那个网络上的储能单元里充电。背架上的条显示它存了多少电。

算力足够的[外骨骼](exosuit.md)飞得快一倍，能飞的时间长十倍。

## 学会飞行

模型在<ItemLink id="flight_dataset" />上通过飞行学会驾驶：核心用模型自己的选择去飞，模型根据每个选择之后的结果来学习，和控制一样。推力改变的是背架上升或下降的快慢，而不是它所在的高度，所以驾驶得从之前的高度读出速度；风向标读到的风每两次或三次查看吹一下，从哪一刻开始吹却不一定，驾驶得从飞行过程中看出来，并在它吹之前迎上去。只能看到最后几个字符的模型，在最难的那种风里稳不住一半的飞行；两块的 Transformer 练大约一千步就能全部稳住。见[模型与测试](models.md)。
