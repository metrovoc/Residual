# 模型驱动器

<ItemLink id="model_drive" />用来存放模型。拿在手里它什么也不做：要由[模型核心](core.md)来装它。

<RecipeFor id="model_drive" />

新的驱动器是空白的，它的格子是暗的。它第一次被装进模型核心时，那个核心会在驱动器上启动一个模型；从那时起，这个驱动器就是那个模型：无论被带到多远，哪个模型核心装着它，都会通向同一座大厅。驱动器不可堆叠。

从模型核心中取出后，驱动器会显示它装着什么：

- 模型的任务；
- 模型有多少参数；
- 它在最近一次测试中的表现，测试用的是它没练习过的例子：答对的比例，或者当任务没有对错答案时的损失。

模型尚未测试过的驱动器只会说明这一点。

空白驱动器仍会出现在一些[遗迹](ruins.md)里。
