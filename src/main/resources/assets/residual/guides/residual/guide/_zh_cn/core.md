# 模型核心

<ItemLink id="model_core" />装着一个[模型驱动器](model-drive.md)，也是进入其中模型的入口。

<RecipeFor id="model_core" />

它被放下时，正面朝着放下它的人。空着时，它是暗的；装着驱动器时，各个面会亮起。

## 使用

- 手里拿着模型驱动器时，对空的模型核心使用，把驱动器放进去。空白驱动器会在那一刻得到它的模型。
- 空手时，对装着驱动器的模型核心使用，进入模型内部。
- 空手时潜行并使用它，把驱动器取到那只手里。
- 破坏模型核心，驱动器会掉在旁边。

## 内部

模型是一座大厅，你抵达的是它的近端。那里立着一排控制台；对其中一个使用即可操作：

- **离开**把你带回你踏入时站的地方。
- **任务**改变要求模型做的事：阅读、倒序、规律或回忆。
- **训练**让模型开始训练，再按一次则暂停。
- **单步**让它训练一步。
- **速度**和**学习率**决定它迈步的快慢，以及每一步移动多远。
- **重新开始**给它新的权重。

## 模型核心装着驱动器时

正在训练的模型会在你离开后继续训练，里面没有人；只要有一个模型核心装着它的驱动器，且模型核心所在的地块仍处于加载状态。取出驱动器，大约十秒后，模型会按当前状态被收起。把驱动器放回任意一个模型核心，模型就会再次出现，处于暂停状态：进去并使用**训练**。
