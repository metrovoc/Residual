# 模型核心

<BlockImage id="model_core" scale="3" float="left" />

模型核心把文本送进你的机器，并评判送回来的结果。它的正面发出词元；其余各面接收模型的分数。它训练模型、测试模型，并把它保存为一个模型。训练好的权重留在机器本身之中，所以你离开再回来时，模型学到的东西依然还在。

<br clear="all" />

<RecipeFor id="model_core" />

## 数据

四个槽放模型练习用的东西：数据集、档案驱动器或打捞模型。其中所有内容一起练习，轮流各取一个批次。旁边是分词器槽，决定模型读写的[词元](tokenizers.md)，以及检查点槽，并显示其中检查点保存的内容。「存入检查点」会在每项基准上测试模型，并把它存进那个检查点。装入打捞模型时，「重建」会在核心前方搭出它的机器：见[打捞模型](salvage.md)。

## 训练

学习曲线、当前数值和训练设置。各项含义见[训练](training.md)。**参数**统计模型的权重数；**梯度范数**是最近一次梯度的大小；**线程**是核心训练所用的线程数。

## 测试

每项基准、它上次测试的分数，以及通过所需的分数。每项基准的测试在模型用它训练时进行；「全部测试」会立即运行所有测试。把鼠标悬停在基准上，可查看其测试所用的格式。见[模型与测试](models.md)。

## 试用

运行模型。选择一项基准：「样例」会抽一个新的测试样例，展示模型如何作答，就像智能体提问时那样。指令基准下，输入一条指令并点「提问」；阅读基准下，输入一段开头并点「续写」：模型会一个字母一个字母地接着写下去，每个字母都按其预测的概率抽取。**温度**在抽取之前让这些概率变得更尖锐或更平缓：

![temperature](/formulas/temperature.png)

温度低时，模型重复它最偏爱的续写；温度高时，它更敢冒险。柱条显示模型对它写出的第一个字母的每个候选认为有多大可能。

## 检查

模型的每台机器，按数据到达的顺序排列，附有输出形状、权重数量和最近一次梯度的大小。「校验」发现的问题也列在这里。若柱条沿列表往下逐渐缩到没有，那就是一个始终到不了的梯度。

## 更多线程

<ItemImage id="accelerator" float="left" />

每台与核心相接（直接相接，或经由其他训练加速器相连）的<ItemLink id="accelerator" />，都会借给它多一个线程，上限由服务器设定。没有东西冷却的训练加速器会过热，只借出一半：让它接触水、冰或雪。制造机用矩阵乘法光掩模制造它们。
