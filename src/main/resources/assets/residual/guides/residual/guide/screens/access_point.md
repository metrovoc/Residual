# An Access Point's screen

Use an Access Point to open it. [Storage](../storage.md) tells how far terminals reach.

A slot for a Relay Card, and a mark for how far it reaches.

<residual:Shot name="access_point_card" alt="An Access Point with no card">
  <residual:Part name="card">
    **Relay Card**: A Relay Card tuned to a Model Server. With one here, Wireless Terminals reach this network anywhere that server's relays cover.
  </residual:Part>
  <residual:Part name="light">
    **Its reach**: Teal with power in a Link Driver on its network, amber with a Relay Card that reaches. Point at it for how many blocks.
