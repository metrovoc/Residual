# Residual

在你之前，有人住在这里。他们造出了会思考的机器，并把一切都写了下来。后来，他们不在了。他们留下的东西还会在遗迹中零星出现：写满文字的破碎石板、机器的设计，以及再也无法运转的模型。

这是一份重新造出模型的手记：由机器搭成的语言模型，每台机器只做一种运算，用线缆连成网络，在文本上训练，再用从未见过的文本测试。好的模型能种田、管储物间、跑腿、续写规律、凭名称认出东西、听懂你的话、读懂旧世界写下的文字，还能看出一片田地的走向。
