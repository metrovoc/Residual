# Residual

在你之前，有人住在这里。他们似乎造出了会思考的机器，并把一切都写了下来。后来，他们不在了。他们留下的东西还会在遗迹中零星出现：写满文字的破碎石板、机器的设计，以及再也无法运转的模型。

这是一份重新造出模型的手记：由机器搭成的语言模型，每台机器只做一种运算，用线缆连成网络，在文本上训练，再用从未见过的文本测试。一个知道周围方块接下来会怎样的模型，能让预报机把它们超前运行。别的模型能续写规律、凭名称认出东西、把你的话写成智能体的程序，还能读懂旧世界写下的文字。
