# Residual

在你之前，有人在这个世界生活过。他们已经不在了，但遗迹中仍留有他们的痕迹。最神秘的是，他们似乎造出了会思考的机器。

这些是关于重新造出模型的野外笔记：模型保存在驱动器上，模型核心装着驱动器，而模型是一座你可以踏入、走过并训练的大厅。
