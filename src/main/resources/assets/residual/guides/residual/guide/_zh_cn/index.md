# Residual

在你之前，有人在这个世界生活过。他们已经不在了，但遗迹中仍留有他们的痕迹。最神秘的是，他们似乎造出了会思考的机器。

这是一份重新造出模型的手记：由机器搭成的语言模型，每台机器只做一种运算，用线缆连成网络，在文本上训练，再用从未见过的文本测试。一个知道周围方块接下来会怎样的模型，能让预报机把它们超前运行。别的模型能续写规律、凭名称认出东西，还能读懂旧世界写下的文字。
